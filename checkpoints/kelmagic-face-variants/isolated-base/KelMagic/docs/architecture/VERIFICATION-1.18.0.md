# Проверка KelMagic 1.18.0

Minecraft1.21.1 / NeoForge21.1.256 / Java21. Финальный `build runGameTestServer` успешно завершён: **168 обязательных GameTest**, **67127 проверок ядра**. Лог — verification-logs/GAMETEST-1.18.0.log.

## Реальные игровые проверки
- Все18 доступных исследовательских путей проходят финальный точный подбор центра/кольца и смыслового слова: 100ticks на образец, запрет раннего завершения, расход кольца, зарегистрированный правильный результат (включая содержимое зелья), авторский лист открытия, чтение/право изготовления, запрет повторного запуска.
- Неизвестное слово запрещает гипотезу без расхода бумаги; неверный токен, чужая бумага, отсутствие последнего этапа и несоответствующий центр/лишние образцы не дают результата. Слово запускается через настоящую производственную ветку ServerChatEvent и не попадает одновременно в обычную SpellSession.
- Слоты нельзя менять/забирать/shift-перемещать во время наполнения. Закрытие меню оставляет все9 вещей. NBT сохраняет содержимое, уже потраченный слот, порядок, курсор, владельца и длительность. Offline/отсутствие бумаги ждут без дополнительного расхода; продолжение выдаёт один результат.
- Разрушение настоящего блока вызывает onRemove и сбрасывает ровно девять остающихся реальных вещей.
- Реальный CraftingMenu проверяет девять ядер -> блок и полный7-типный рецепт станции: два любых бревна, два железных блока, блок маны, аметистовый/медный блоки, гладкий камень, чернила. Обе вещи доступны без личного исследования.
- Нативный крафт шерсти и самородков для нити остаётся покрыт тестом. Образцы больше не исчезают из рюкзака у архивистского стола; финал использует только помещённые в станцию вещи. Перенос гипотезы во вторую руку и отдельные наблюдения одеяний проверены.
- Зарегистрированный NPC создаётся взрослым, мирным, persistent, с коллизией2.5блока и28здоровья. Две подряд попытки разговора дают одну реплику и не расходуют предмет. MageDynamics проверяется на импульс, затухание,1000крайних входов, пределы и NaN.
- Сохранены остальные проверки заклинаний, исследований, слов, личных заметок/достижения, поиска, рецептов, варки и нативной медной письменности.
