# Проверка KelMagic 1.5.1

Minecraft 1.21.1 / NeoForge 21.1.256 / JDK 21 (Eclipse Adoptium, загружен Gradle toolchain).

## Фактические результаты
- BUILD SUCCESSFUL, финальная команда выполнена после последних изменений Java.
- CORE TESTS PASSED: 367 checks.
- All 54 required tests passed. Прежние 43 + 11 новых GameTest.
- ASSET CHECKS PASSED: 228 (с исходным src 1.5.0 как базой сравнения).
- Проверены JSON, реальные рецепты всех 14 артефактов, симметрия всех слоёв иконок, обращённый порядок каждого кадра обоих спрайтов, неизменность ядра маны и файлов глифов/шрифта, длительность сущностей, mixin и fire tag.
- В готовом JAR проверены версия 1.5.1, mod id kelmagic, описание, общий mixin и тег огня.
- В офлайн-превью просмотрены 14 страниц артефактов, иконки и парная отделка. 28 проверок границ текста в страницах с метриками bitmap-шрифта Minecraft. Превью не являются скриншотами запущенного клиента; 3D-иконки ванильных блоков там приближены исходной гранью, декоративные кнопки упрощены.

Новые GameTest: точное истечение на 100 тиках; обычный/душевный костёр с 6 сторон и мокрый костёр; порталы X/Z; повреждённая рамка; поджиг портала сбоку без опоры; портал при doFireTick=false; настоящий жареный лут свиньи, коровы, курицы, овцы (в том числе последний тик) при Fire Resistance и без ванильного огня.

## Команда проверки в этой среде
```
JAVA_HOME=<JDK21> _JAVA_OPTIONS='-Xmx1800m -XX:ActiveProcessorCount=2' bash ./gradlew -I tools/binary-build.init.gradle build runGameTestServer --max-workers=1 --console=plain
python tools/verify_revision151_assets.py <исходный-src-1.5.0>
```
`tools/binary-build.init.gradle` — необязательная настройка официального binaryPatch режима NeoFormRuntime. Исходные build.gradle, версии и toolchain не изменены; обычная сборка остаётся `bash ./gradlew build`. Эта среда располагает примерно 4 GiB памяти: две попытки полной декомпиляции были убиты из-за OOM; последний ограниченный запуск столкнулся с нехваткой Java heap и был остановлен. Вместо продолжения повторов выбран официальный бинарный путь, который завершился успешно. Он применяет опубликованные бинарные патчи NeoForge и не выдаёт исходники Minecraft для IDE. Сборка самого мода и GameTest полноценные, это не ручная упаковка старых .class.

Предупреждения: 6 ранее существовавших deprecation warnings EventBusSubscriber.Bus; Gradle сообщает о deprecated features для будущего Gradle 10. Они не помешали сборке и тестам.

## Не проверено здесь
Нативный графический клиент новой версии не запускался. Визуальную проверку 1.5.0 нельзя переносить на 1.5.1. Остаются: фактический вид UV в движении, направление анимации в игре/на экране, меню модов, разные GUI scales, render mods/shaders и два настоящих клиента в multiplayer.
