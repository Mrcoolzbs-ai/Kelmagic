# Передача KelMagic 1.12.0

Продолжайте существующий проект, не переписывайте. Прочитайте START_HERE, COMMANDS, VERIFICATION-1.12.0 и политики команд/достижений.

## Изменения 1.12
- ArchiveCommandMixin перехватывает только прямой архив и чистый архивный тег у LocateCommand. ArchiveSearch — серверная очередь, максимум2 задачи, целевой бюджет2мс,120с,LRU2048/TTL5мин. Результат команды1=очередь, координаты позже. Уникальный билет STRUCTURE_STARTS на задачу; освобождать при завершении/замене/отмене/выходе/остановке.
- ArchiveChunkAccess вызывает private getChunkFutureMainThread: публичный getChunkFuture скрыто вызывает managedBlock! Не заменять на него и не читать мир с worker thread.
- Старый ArchiveLocator остаётся синхронным для некомандных API и смешанных тегов. Не заявлять, что абсолютно все поисковые API асинхронны.
- generate_revision_1_12.py закрывает UV(48,22..52,26) верхов рукавов. generate_archives_1_12.py писать после визуального генератора:15 NBT,3 планировки, полный final_state у дверного jigsaw, деревянные скатные крыши. Vanilla pool веса×12 и3 архива×1 сохраняют частоту1.11.
- 35 достижений: archive_route только за успешный поиск игроком.

## Сохранённые изменения 1.11
- ArchiveStructure — поисковая запись для реальных архивных pieces внутри vanilla village starts, без собственного structure set и дублирующей генерации. ArchiveLocateMixin интегрирует её в ChunkGenerator.findNearestMapStructure; SinglePoolElementAccessor читает template ID без сериализации. Поддержка прямого имени и тега, загруженных/неисследованных областей, смешанных HolderSet. Не обходить ванильные права оператора.
- Правило mirrored geometry обязательно согласовано с каноническими UV из generate_revision_1_11.py. Все левые конечности и положительные парные панели зеркальные. Не переносите старую генерацию поверх новой.
- 1440 equipped textures, только 80 material-only inventory models (как vanilla). TrimAppearance.index остаётся pattern+material, materialIndex используется только item predicate.
- GlyphRenderer не трогает глобальные буферы при отсутствии надписей; строки/ширины кэшированы, GlyphReload сбрасывает кэш. HUD рамка — один draw call.
- Невидимые AGE/PULSE magic fire не отсылаются клиенту при неизменной форме. Настоящие визуальные изменения, распространение и удаление синхронизируются.
- hasData-guards не создают эффекты у обычных мобов. Не ослаблять авторизацию, срок креатива, проверки защиты, лимит 100 слов и сохранение игровых эффектов ради оптимизации.
- 34 достижения; archive_patron выдаётся только сервером после сделки с архивариусом. Оформление без формул, announce_to_chat с учётом gamerule.

## Среда
JDK21; в стенде /data/jdk21. При 4GB RAM не запускайте клиент и GameTestServer одновременно. Xvfb/llvmpipe — software renderer, не RTX-бенчмарк. Не выдавайте исторические результаты/шумные измерения за текущий прирост FPS. Проверяйте CRC и побайтное совпадение JAR с ресурсами перед выдачей.
