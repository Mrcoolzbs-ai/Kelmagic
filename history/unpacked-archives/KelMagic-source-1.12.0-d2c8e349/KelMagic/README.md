# KelMagic 1.12.0

Магический язык и архивариусы для Minecraft 1.21.1 / NeoForge 21.1.256 / Java 21.

- `START_HERE.md` — установка, изменения и реальные ограничения.
- `COMMANDS.md` — команды мода и ванильный поиск архива.
- `docs/architecture/VERIFICATION-1.12.0.md` — проверки конкретной сборки.
- `docs/architecture/COMMAND_POLICY.md`, `ADVANCEMENT_POLICY.md` — требования к следующим обновлениям.
- `docs/kel-language/CATALOG-1.12.0.md` — 180 отдельных слов.

Обновление 1.12: неблокирующая очередь ванильного поиска архива, исправленные задние плечи архивариусов, полный порог двери и 15 различных архивов с биомными крышами. Предыдущие оптимизации и игровые механики сохранены.

```bash
JAVA_HOME=/path/to/jdk21 bash ./gradlew -I tools/binary-build.init.gradle build runGameTestServer --max-workers=1
python tools/verify_revision_1_12.py
```

Графические стенды `Qa*` выключены по умолчанию и исключены из релизного JAR. Исходники и документация исторических версий сохранены, но не заменяют сведения текущего релиза. Внешний мультиплеер/шейдеры/производительность на компьютере пользователя отдельно не проверены.
