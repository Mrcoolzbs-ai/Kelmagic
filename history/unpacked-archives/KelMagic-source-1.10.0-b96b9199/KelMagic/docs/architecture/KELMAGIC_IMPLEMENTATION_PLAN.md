# План реализации Kel Magic

## Текущий результат
Источники и расхождения согласованы. Минимальный цикл реализован: ядро, сервер, сеть, чат, bitmap-глифы, сохранение маны. Сборка/367 assertions/16 GameTest проходили до сброса среды; после восстановления проверяются заново. Подробности и оставшиеся проверки в VERIFICATION.md. К следующим этапам пока не переходили.

## Этап 1 — минимальный полный игровой цикл
1. Канонический словарь с provenance; отдельный декларативный реестр магических слов. Первые 6: mina tuna sila no lu pir.
2. Карта 13 согласных и 5 отдельных гласных; прозрачный атлас из writ.png с визуальной сверкой, не случайные руны. Проверить разные слова и ролевые окончания.
3. Чистый парсер мультимножества слов, независимый от перестановок, понятная обработка неопределённых сочетаний. Правила повторов только явно заданные.
4. Сериализуемое состояние маны на игроке через API NeoForge 21.1.256; временная последовательность отдельно. Очистка при смерти/выходе. Траты и регенерация на сервере.
5. Обычный публичный чат — отдельное слово сохраняется в чате. Клиентское повторное открытие, пустой Enter специальным пакетом, Esc отменяет. Токен/поколение последовательности защищает от повторного исполнения. Проверять реальные API текущих зависимостей.
6. Серверные цели: raycast игрок/моб, self; огонь через статус сущности, блок огня только в допустимой позиции. lu расширяет выбор и область по документированным ограниченным правилам.
7. Синхронизация последовательности наблюдателям; настоящий мировой рендер глифов, рассеивание, bounded effects.
8. Срыв на 101-м слове: ограниченная разрушительная очередь и масштабный визуальный эффект, не ванильный взрыв 200000. Не грузить чанки ради эффекта.
9. Автотесты парсера, перестановок, маны и лимитов; Gradle build; запуск клиента и dedicated server; ручные/multiplayer тесты. Не считать визуальный код проверенным по одной компиляции.
