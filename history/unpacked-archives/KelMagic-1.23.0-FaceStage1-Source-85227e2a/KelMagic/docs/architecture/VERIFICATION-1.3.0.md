- Непокрашенные четыре предмета одеяний и новые ядро/слиток видны в инвентаре, отсутствующих текстур нет.
- Оба комплекта осмотрены в третьем лице. Новый капюшон/складки/пояс и латы/наплечники отображаются.
- Скриптер: armed → mina/no/pir в своём чате → пустой Enter → captured → ПКМ saved → Shift+ПКМ эффект огнестойкости. Сообщения фиксируют три слова и цену 5.
