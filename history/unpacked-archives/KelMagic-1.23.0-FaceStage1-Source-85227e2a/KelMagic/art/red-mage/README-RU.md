# Рыжая чародейка — модель1.19

Взрослый человеческий NPC, рост2,5блока. Исходный скин сохранён в original-skin.png; concept.jpg — предоставленный ориентир костюма.

red_mage.bbmodel открывается в Blockbench; red_mage.png — атлас128×128; rig.json — редактируемый исходный скелет26частей для генератора tools/generate_red_mage_1_18.py (историческое имя сохранено). Плечевые верхние UV заполнены. Отдельные наклонённые объёмы груди, одежда полностью закрыта, размер приблизительно4–5. Наклон и разворот хранятся в костях модели. Физика выполняется в игровом коде MageDynamics/RedMage/RedMageModel и не проигрывается автоматически в Blockbench.

Собственная реализация после изучения Wildfire's, без скопированного исходного кода: docs/third-party/WILDFIRE-REFERENCE.md. Нет Fabric-зависимости. Реплики и характер — в локализации KelMagic.
