# Каталог Этапа 1

Декларативный источник: src/main/resources/data/kelmagic/magic/spells.json. Шесть слов подтверждены gram1/gram2/ez_word1; игровые значения заданы автором. Технические пределы — решения реализации, не правила языка.

| Слова (порядок не важен) | Мана | Результат | Проверка |
|---|---:|---|---|
| pir | 3 | Огонь в допустимой позиции на блоке прицела | pir |
| tuna + pir | 7 | Поджечь игрока прицела (при разрешённом PvP) | tunaPir |
| sila + pir | 7 | Поджечь моба прицела | silaPir |
| mina + pir | 7 | Поджечь самого заклинателя | чистый парсер; отдельный игровой тест пока не добавлен |
| mina + no + pir | 9 | Огнеупорность заклинателя | minaNoPir + настоящий клиент |
| lu + pir | 5 | Несколько блоков огня около блока прицела | luPir |
| lu + tuna + pir | 9 | Поджечь игроков в области вокруг цели/точки прицела | парсер; отдельный групповой player-тест ещё нужен |
| lu + sila + pir | 9 | Поджечь мобов в области вокруг цели/точки прицела | luSilaPir |
| lu + tuna | 6 | Селектор игроков; без эффекта завершённого заклинания нет | luTuna |

Всего 9 определений: 8 сочетаний с эффектом и 1 неполный селектор. Это НЕ 200–300 заклинаний; перестановки не считаются новыми сочетаниями.

Пределы по умолчанию: raycast 24 блока, lu радиус 8, до 32 сущностей или 16 огней; горение 10 секунд, огнеупорность 60 секунд. Сущности сортируются по расстоянию, затем UUID. Стены и режим PvP учитываются. Конечный огонь ставится в допустимую пустую позицию; placement event можно отменить с откатом.

Повторные слова и несколько агентов не поддержаны в каталоге. lu + mina + pir пока неопределён, чтобы не подменять сам заклинатель другой категорией и не игнорировать lu молча. no + pir без агента тоже пока неопределён.
