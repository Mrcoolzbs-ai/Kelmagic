# Проверка KelMagic 1.17.0

Minecraft 1.21.1 / NeoForge 21.1.256 / Java 21. `build runGameTestServer` прошёл: **161 обязательный GameTest** и **66124 проверки ядра**. Лог: `verification-logs/GAMETEST-1.17.0.log`.

## Новые и сохранённые проверки

- Реальный ванильный CraftingMenu: шерсть из четырёх нитей, золотые самородки из слитка, этапы и три отдельных сообщения. Неправильная сетка не засчитывается. Проверен proximity tick у настоящего стола, точный расход образцов, отсутствие повторного спама, чтение открытия и рецепт.
- Реальный крафт щита одновременно продвигает две носимые гипотезы, одна во второй руке; у каждой своя мысль. Убранный лист не принимает образец; оставшийся продолжает.
- Все наблюдательные этапы теперь имеют конкретные сигналы изготовления или сохранения записи. Каждый названный результат обычного изготовления — настоящий зарегистрированный предмет с рецептом. Это проверка наличия всех рецептов, а не ручной проход каждого из 18 направлений от начала до конца.
- Новое достижение зарегистрировано. Пустая заметка и неизвестное слово не выдают его, собственная непустая заметка к известному слову выдаёт. Проверены сохранение заметок и параметры книги, фильтр/порядок, нормализация приветствия в допустимый раздел и NBT сохранение.
- Сохранены прежние тесты авторизации бумаги, закрытых рецептов, варки, медной письменности, сохранения прогресса, артефактов, мировых эффектов и команд.
