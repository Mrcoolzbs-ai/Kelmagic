## Ограничения
Старые деревни не перестраиваются. Случайная генерация не гарантирует архив в каждой деревне. Фоновый locate возвращает первый проверенный реальный дом,не доказанный globalnearest;генерация/GC/сторонние моды всё ещё могут влиять на время. Тестовый мир требует мод1.14. Сторонние шейдеры/worldgen-моды,внешний мультиплеер и FPS ноутбука отдельно не проверялись.
