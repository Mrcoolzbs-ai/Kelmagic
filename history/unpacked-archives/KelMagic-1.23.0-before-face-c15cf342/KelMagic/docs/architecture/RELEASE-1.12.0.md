# KelMagic 1.12.0

Minecraft **1.21.1**, NeoForge **21.1.256**, Java **21**. Сделайте резервную копию мира, удалите предыдущий JAR и установите `kelmagic-1.12.0.jar` на клиенте и сервере. Формат сохранений и протокол 6 не изменены.

## Исправления
- **Плечи архивариусов сзади:** закрыты верхние поверхности рукавов, которые пропускали коричневую ванильную текстуру. Исправление для всех семи биомных одежд; кисти и сложенные руки сохранены.
- **Поиск без синхронного ожидания:** `/locate structure kelmagic:archive` и `/locate structure #kelmagic:archives` ставят поиск в очередь. Можно продолжать играть; результат с ванильными координатами и кликабельной телепортацией приходит позже в чат. Проверяются реальные архивные дома внутри деревень, включая неизученные области, а не произвольные столы.
- **Порог:** под дверью теперь полный блок пола, не ступенька.
- **Крыши:** дубовые, еловые и акациевые архивы получили скатные крыши из ступеней, со свесами, коньком и заполненными фронтонами. В пустыне — плоская терраса в местном стиле.
- **15 построек:** по три планировки для равнин, пустыни, тайги, снежных деревень и саванны: читальный зал, длинная библиотека с двумя рядами полок, зал с отдельным кабинетом. Разные размеры и интерьер, а не только перекраска. Частота появления архивов сохранена.

**Новые планировки появляются в новых чанках.** Уже построенные архивы не перестраиваются автоматически. Текстуры и новый поиск работают и в старом мире.

## Поиск
```mcfunction
/locate structure kelmagic:archive
/locate structure #kelmagic:archives
/kelmagic admin locate cancel
```
Нужны права оператора уровня 2. Повторный запрос заменяет ваш предыдущий; одновременно работают максимум два поиска. Тайм-аут — 120 секунд. Поиск может занять время и записать новые начала структур, но больше не ждёт их готовности внутри вызова команды. Обрабатывается по одному кандидату за тик на задачу, целевой общий бюджет обработки очереди — 2 мс. Это не обещание отсутствия любых лагов от генерации, других модов или GC.

Если генерация структур отключена, поиск не включает её. Старый `/kelmagic admin locate archive [чанки]` оставлен для ограниченного поиска по загруженным началам деревень.

Для командных блоков/функций: немедленный результат новой команды — **1 за постановку в очередь**, не расстояние до архива. Координаты приходят отдельно после завершения.

## Дополнительно
Новое достижение **«След по каталогу»** за успешный поиск архива игроком. Без формулы, объявление учитывает `announceAdvancements`. Всего 35 достижений с корневой вкладкой. Сохранены все 180 слов, отделка 18 × 10 материалов, оптимизации 1.11 и механики 1.10.

Подробные команды — `COMMANDS.md`. Результаты проверки — `docs/architecture/VERIFICATION-1.12.0.md`. Тестовый OpenGL программный, не измерение FPS на вашем ноутбуке.
