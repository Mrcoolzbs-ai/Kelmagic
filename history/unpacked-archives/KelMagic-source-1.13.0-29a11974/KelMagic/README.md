# KelMagic 1.13.0 — То, что осталось после голоса

За тихими деревнями стоят пустые города. В книгах ещё видны следы чужого дыхания, а оставленные механизмы ждут голоса, который больше не вернётся. Собирайте строки Кэл — и решайте, какие слова стоит произносить снова.

Minecraft1.21.1 / NeoForge21.1.256 / Java21.

- START_HERE.md — установка, изменения и ограничения поиска.
- COMMANDS.md — управление, фоновые /locate и отмена поиска.
- docs/lore/KEL-CHRONICLE-1.13.0.md — авторская сюжетная основа со спойлерами, адаптация предоставленной теории MrGridlock; не официальный канон.
- docs/kel-language/CATALOG-1.13.0.md —180 отдельных художественных описаний.
- docs/architecture/VERIFICATION-1.13.0.md — проверки конкретного релиза.

Словарь и механики не менялись. Практические заметки доступны через Shift. Архивы чаще выбираются в новых чанках, результат поиска больше не ждёт окончания кольца. Достижение за поиск командой удалено.

```bash
JAVA_HOME=/path/to/jdk21 bash ./gradlew -I tools/binary-build.init.gradle build runGameTestServer --max-workers=1
python3 tools/verify_revision_1_13.py
```

Графические стенды Qa* исключены из релизного JAR. Исторические документы не заменяют проверки текущей версии. Гарантированный результат поиска в любом сидe и прирост FPS на устройстве пользователя не заявляются.
