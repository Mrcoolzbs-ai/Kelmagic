## Архитектура и ограничения
- ArchiveCommandMixin перехватывает только прямой `kelmagic:archive` и чистые архивные теги. Обычные структуры и смешанные теги сохраняют прежний API-путь. Старый ArchiveLocator для некомандных вызовов остаётся синхронным.
- ArchiveSearch выполняется на server thread, запрашивает private getChunkFutureMainThread через invoker, опрашивает isDone/getNow; не использует публичный wrapper getChunkFuture с managedBlock. Мир не читается на произвольном worker thread.
- Максимум2 задачи, один кандидат/опрос на задачу за тик, целевой бюджет обработки2мс. Уникальный билетSTRUCTURE_STARTS на каждую задачу, освобождение при завершении/ошибке/замене/отмене/выходе/смене измерения/остановке. Cache2048,TTL5мин, очищается при datapack sync/остановке. Тайм-аут120с.
- Команда немедленно возвращает1 за очередь, не найденное расстояние; окончательные координаты позже. Скриптам/command blocks следует учитывать это отличие.
- Биомные деревенские дома обновляются только в новых чанках. Дома не генерируются отдельно от деревень. Частота сохранена: vanilla веса×12 и3 архива×1 вместо×8 и2×1.
- Не проверялись внешние два клиента, сторонние worldgen/структурные моды, шейдеры, реальный RTX3050Ti и FPS пользователя. Продолжение серверных тиков — не гарантия отсутствия любой задержки генерации/GC/других модов.
