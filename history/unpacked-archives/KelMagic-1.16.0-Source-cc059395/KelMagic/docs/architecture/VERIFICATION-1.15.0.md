# Проверка KelMagic 1.15.0

- Java 21, Minecraft 1.21.1, NeoForge 21.1.256.
- `build runGameTestServer`: успешная сборка; **157 обязательных игровых тестов прошли**.
- В исследовательском наборе: стоимость/авторизация гипотезы, превращение и применение открытия, защита чужих/поддельных листов, ровно 23 поддерживаемых знака на камнерезе, снятие книги и устаревший результат, базовые рецепты, сохранение состояния, закрытая великая формула, настоящий admin cast/reveal/unlock, реальный верстак и сохранность ингредиентов, сборщик, раскрытие рукописи, найденный скриптер, реальная блокировка и разблокировка варки.
- В окончательном GameTest полного цикла и изменение на себе, и внешнее изменение блока проверены настоящими заклинаниями: `mina pir`, затем `pir` по подготовленной мишени. Полный ручной прогон всех комбинаций опытов не заявляется.
- Совместимость со всеми сторонними модами не проверялась. Блок-сборщик не имеет исследователя и не производит закрытые исследованиями вещи даже после их персонального изучения.
- Подробный лог: `verification-logs/GAMETEST-1.15.0.log`.

## Нативный клиент

`runClient` под Linux/Xvfb, программный OpenGL, русская локализация. Успешно открыт реальный тестовый мир, выполнены реальный клик по узлу для записи гипотезы, сетевой запрос потратил ровно один лист бумаги. Перетаскивание карты проверено настоящими методами ввода. Завершение гипотезы и чтение открытия проверены на серверной стороне; внешнее наблюдение в клиентском стенде подано тестовым сигналом, не ручным действием. В GameTest полного цикла внешний опыт проверяется отдельно.

12 кадров: старт, слова, материалы, активная гипотеза, уведомление/новые ветви, рецепт, звук, закрытая секретная закладка, одеяния с GUI scale 3, лор, мысль, пример применения. Кадры осмотрены; легенды ограничены по ширине, тексты и рецепты не перекрываются. Узлы за краем карты намеренно обрезаются областью прокрутки; перетаскивание открывает их. При прочтении открытия временные ванильные и модовые уведомления могут перекрывать край кодекса.

Лог `verification-logs/NATIVE-RESEARCH-1.15.0.log`, изображения `native-research-1.15.0/`. Последний клиентский прогон сохранил мир после сброса знаний, наполнения стартового набора и возврата в выживание. Перед упаковкой старт и 23 слова дополнительно проверены по NBT, режим мира по умолчанию также выставлен в выживание.

## Ресурсы

33 уникальных узла, без циклов и отсутствующих предпосылок; ключи лора присутствуют в обеих локализациях, иконки существуют. Все 20 обычных рецептов мода покрыты каталогом; 1440 рецептов медной письменности охватывают все 180 слов. Проверка `tools/verify_research_1_15.py`.
