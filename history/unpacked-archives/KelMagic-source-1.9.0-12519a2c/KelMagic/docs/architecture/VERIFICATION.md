# Проверки Этапа 1

## До прерывания / сброса среды
- `./gradlew build` завершился BUILD SUCCESSFUL.
- Чистый Java-runner CoreTests: 367 проверок/assertions (это не 367 отдельных JUnit-тестов).
- NeoForge GameTestServer: все 16 обязательных игровых тестов прошли.
- Реальный Minecraft-клиент запущен в Xvfb с Mesa software rendering. Это не макет интерфейса.
- В отдельном survival/peaceful superflat-мире проверены HUD маны, ввод mina через обычный чат, сохранение публичного сообщения, повторное открытие чата.
- Обычное сообщение hello не сбросило подготовленную последовательность.
- Исправлен знак масштаба X мирового текста: Minecraft 1.21.1 использует положительный X и отрицательный Y, как в EntityRenderer. После исправления настоящие глифы видны в воздухе.
- Ввод mina, no, pir по одному накопил три слова и глифы; пустой Enter закрыл сборку и дал настоящую огнеупорность, глифы исчезли. См. screenshots/previous-client-*.png.
- Последняя правка добавила тень к мировому тексту для читаемости. До сброса повторная визуальная проверка этой небольшой правки не была завершена.
- Системные предупреждения local-client: отсутствуют звуковое устройство OpenAL и библиотека narrator/flite. Клиент работал; это не ошибка магии.

## После восстановления
Код восстановлен из сохранённых точных команд с внесением финальных исправлений. Повторная проверка: BUILD SUCCESSFUL; CORE TESTS PASSED: 367 checks; All 16 required tests passed. Новый JAR скопирован в release.

Финальный клиент также запущен заново: новый survival/peaceful superflat-мир, HUD маны 5/5, ввод mina/no/pir через публичный чат, автоматическое повторное открытие чата, три слова и настоящие глифы в воздухе с тенью проверены визуально. Пустой Enter завершил последовательность: глифы исчезли, в инвентаре подтверждена огнестойкость (00:57 на снимке). Снимки final-mina.png, final-glyphs.png, final-cast.png. Проверка двумя клиентами и нагрузочная проверка overload не проводились.

## Не подтверждено
- Полноценный multiplayer двумя реальными клиентами; GameTest использует серверных тестовых игроков.
- Визуальный масштаб катастрофического облака и профилирование разрушительного overload на разных серверах. Тест word101 отключает разрушение тестового мира и проверяет смерть/очистку состояния.
- Реальный повторный вход с неполной маной и взаимодействие с другими модами защиты территории. Codec roundtrip и copyOnDeath проверены игровыми тестами, но это не заменяет все сценарии reload/rejoin.
- Броня, зелья, скриптер, сердце дракона как предмет, книга, структуры и 200–300 сочетаний не реализованы.
