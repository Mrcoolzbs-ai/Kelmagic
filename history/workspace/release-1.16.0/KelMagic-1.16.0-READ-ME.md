# KelMagic 1.16.0 — Листы, которым есть что сказать

Minecraft **1.21.1**, NeoForge **21.1.256**, Java **21**. Сделайте резервную копию мира, удалите прежний JAR и установите `kelmagic-1.16.0.jar` на клиенте и сервере. Новый сетевой протокол 8; старые слова, заметки, вещи и знания сохраняются.

## Что изменилось

- Золотая нить больше не требует `pir` или других заклинаний: белая шерсть из четырёх нитей → золотые самородки из слитка → одна нить и самородок у стола.
- Подходящие действия автоматически продвигают все носимые собственные гипотезы. После каждого этапа в чат приходит отдельная мысль персонажа. В каталоге 51 комментарий к этапам.
- Материальные образцы проверяются автоматически у стола в пределах примерно 2,5 блока. Образцы расходуются только при полном комплекте и ровно один раз на этап.
- Кодекс снова компактная книга: приветствие, боковые закладки с иконками, прежние страницы слов без лишних кнопок, живые чернильные карты, волнообразные связи и недоступные превью.
- Клик по изученной иконке открывает отдельную многостраничную книгу: мысли и лор, рецепт, художественный способ применения.
- Дубли исследований между разделами удалены. В каталоге 31 уникальный узел.

Подробно: `docs/design/RESEARCH-1.16.0.md`. Гипотеза после завершения становится открытием, но знание нужно сохранить, прочитав его ПКМ.

## Проверить золотую нить

1. Создайте ядро маны, чтобы открыть материалы. Откройте кодекс и выберите боковую закладку материалов.
2. С бумагой в инвентаре нажмите на иконку золотой нити. Один лист станет гипотезой; оставьте его в сумке.
3. Изготовьте белую шерсть из четырёх нитей, затем самородки из золотого слитка.
4. С обычной нитью и одним самородком подойдите к столу архивариуса. Два маленьких образца будут использованы автоматически. Рядом с вами не обязательно должен находиться открытый интерфейс стола.
5. Возьмите появившееся открытие и прочитайте ПКМ. Затем откройте его страницы в кодексе.

Готовая шерсть и готовые самородки в инвентаре не заменяют действия крафта. Нужен новый результат на соответствующем этапе. Уже выполненные этапы повторять не нужно.

## Мир для проверки

Распакуйте папку **KelMagicResearch116** из ZIP в `.minecraft/saves`. Внутри неё должен лежать `level.dat`. Не открывайте мир без мода.

Старт в выживании: **42, −60, −12**. Исследования сброшены. В инвентаре — кодекс с 23 словами, бумага, обычные материалы, рукопись и найденный скриптер. Рядом добавлен стол для опытов: **42, −60, −9**.

Сохранились прежние 15 архивов и выставочная галерея 592 медных блоков. Новый мод поддерживает весь словарь: 180 слов × четыре стадии × воск/без воска = 1440 вариантов. Камнерез использует только слова кодексов в основном инвентаре или второй руке. При нескольких книгах берётся объединение; без книги право на соответствующие новые надписи пропадает.

Дома по X=0,40,80; ряды по Z=0,40,80,120,160. Галерея меди около X=140–172, Z=0–292. Домики выставочные, размещены вручную; командный `/locate` не ищет эти экспонаты.

## Прежние особенности

Найденные артефакты пригодны к использованию без изучения производства. Ядро, кодекс и стол изготовляются свободно. Великая закладка скрыта; способ обычного открытия ещё не добавлен. Админский `/kelmagic admin cast @s wings` работает независимо от знания, но сохраняет требования самого эффекта.

Автосборщик пока не поддерживает личные исследования. После изучения зелья откройте варочную стойку заново. Поздние гипотезы пока используют несколько общих классов наблюдений; индивидуальные задачи для каждой вещи ещё не реализованы.

Архивы естественной генерации изменяются только в новых чанках. Фоновый `/locate structure kelmagic:archive` и отмена `/kelmagic admin locate cancel` сохранены. Результат поиска не гарантирует математически ближайший дом и не обещает нахождение в любом сидe.
