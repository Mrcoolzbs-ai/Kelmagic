# KelMagic 1.23.0 — статическое лицо, этап 1

Это кандидат для оценки статической геометрии, не новая версия ИИ или анимаций. Версия внутри мода остаётся 1.23.0. Не устанавливайте одновременно оригинальный JAR и кандидат face-stage1.

## Исходное состояние и откат

До правок восстановлен точный выданный KelMagic-1.23.0-Source.zip, а не локальная восстановленная 1.16.0. Сохранены полный исходный архив и SHA256 каждого исходного файла. SHA256 исходного архива: `1ece0e5414befed088f08dab5db528bab9a594c3eb0f25f7f67c73e3b263b70b`.

Комплект Rollback содержит исходные версии пяти изменённых файлов, исходный JAR, контрольные суммы и безопасный скрипт отката исходников. Скрипт сначала проверяет, что пользователь не сделал дальнейших изменений. Подготовительные проверки не изменяют файлы; применение требует `--apply`. Для отката установленного мода замените кандидат оригинальным JAR из комплекта. Мир и его содержимое эта правка не мигрирует.

## Геометрия

- Имена, родители, повороты и точки вращения всех 64 костей сохранены.
- Верхний внутренний и нижний внешний углы глазных проёмов получили небольшие ступени. Поверхности кожи строятся прежним алгоритмом CSG-объединения, без внутренних стенок соседних панелей.
- Добавлена компактная двухступенчатая тёмная верхняя граница каждого глаза. Это статическая форма на голове, не новый анимационный канал.
- Белки приближены к поверхности лица: расстояние от Z=-4 до белка уменьшено с 0.48 до 0.27 модельной единицы. Радужка, зрачок, блик и маски век имеют разные глубины; блики остаются под маской закрытого века.
- Радужки стали немного уже, вертикальные тёмные зрачки и разный цвет глаз сохранены. Схема управления взглядом не изменена.
- Нос вместо одной прямоугольной выступающей детали собран из компактной переносицы и короткой нижней ступени. Максимальное выступание уменьшено с 0.23 до 0.19 модельной единицы.
- Рот сужен: проём 2.6 → 2.2, высота 1.1 → 1.0. Линия губ и внутренние элементы согласованы с новым проёмом. Существующая плоская маска губ и её точка масштабирования сохранены.
- Общее число элементов: 133 → 134. Число поверхностей головы: 47 → 47, включая новые верхние границы глаз. Дополнительный элемент приходится на ступенчатый нос.

Палитра и весь текстурный атлас сохранены побайтно. Для новых поверхностей переиспользованы существующие UV-острова. Никаких чужих моделей или текстур не перенесено.

## Изменённые файлы продукта

1. `tools/mascot_static_face_stage1_1_23.py` — новый отдельный статический слой геометрии лица.
2. `tools/mascot_surface_fixes_1_23.py` — вызов этого слоя после исходных исправлений 1.23.
3. `tools/generate_mascot_1_23.py` — сохранение прежних редакторских UUID неизменённых клипов при экспорте.
4. `art/red-mage/red_mage.geo.json` — синхронизированная исходная геометрия.
5. `art/red-mage/red_mage_gecko.bbmodel` — синхронизированная модель Blockbench с прежними анимациями и встроенной текстурой.
6. `src/main/resources/assets/kelmagic/geo/red_mage.geo.json` — игровой экспорт.

Вспомогательные добавления: `tools/verify_static_face_stage1_1_23.py`, этот документ и `docs/qa/face-stage1-1.23.0/` с ракурсами, read-only рендером и логами. Ни один Java-файл, игровой/исходный JSON анимаций, текстура, рецепт, модель трона, волос или тела не изменён. Новых зависимостей нет.

## Воспроизведение

Из корня проекта:

```bash
python tools/generate_mascot_1_23.py
python tools/verify_revision_1_23.py
python tools/verify_static_face_stage1_1_23.py --baseline /path/to/KelMagic-1.23.0-Source.zip
JAVA_HOME=/path/to/jdk21 bash ./gradlew -I tools/binary-build.init.gradle build runGameTestServer --max-workers=1
```

## Проверки и граница достоверности

Финальная сборка успешна. `coreTest`: 67127 проверок пройдены. Сервер: все 196 GameTests пройдены. Ресурсные проверки и проверка границ изменения пройдены: только пять существующих файлов изменены; анимации Blockbench вместе с UUID, игровые анимации, Java, атлас, все кости вне лица и все точки вращения побайтно/структурно прежние. Исходная и игровая геометрия совпадают, встроенная текстура Blockbench совпадает с игровой.

Ракурсы в папке QA — техническая ортографическая растеризация фактических граней и UV игровых `.geo.json`, не нарисованный заменитель модели и не кадры Minecraft. До/после имеют одинаковые камеру, свет и фиксированные нейтральные значения существующего управления 1.23: веки 0.07, открытие рта 0.12. Контроллеры не исполнялись и не изменялись. Графический клиент Minecraft в этом прогоне не запускался; проверка специфики GPU/шейдеров остаётся отдельной проверкой.

В полном профиле лицо закрывает прежняя боковая прядь. Для оценки носа и углублений сделаны дополнительные диагностические ракурсы, скрывающие волосы и шляпу только в памяти рендера. Игровые волосы и шляпа остаются неизменными.

На этом этапе выражения, моргание, направление взгляда, процедурная физика, волосы, тело и игровая логика не дорабатывались. Следующий этап — только после оценки статической модели.
