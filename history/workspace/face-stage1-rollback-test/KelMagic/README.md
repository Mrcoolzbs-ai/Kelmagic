Словарь сохранён. Кодекс переработан в открываемые событиями закладки и перемещаемый граф исследований; гипотезы требуют бумаги, реальных наблюдений и недорогого образца. Подробнее: docs/design/RESEARCH-1.17.0.md. Заметки по Shift удалены; художественные описания предметов остаются только в кодексе, рукописи сохраняют лор. Архивы чаще выбираются в новых чанках, результат поиска больше не ждёт окончания кольца. Достижение за поиск командой удалено.

```bash
JAVA_HOME=/path/to/jdk21 bash ./gradlew -I tools/binary-build.init.gradle build runGameTestServer --max-workers=1
python3 tools/verify_revision_1_19.py
```

Графические стенды Qa* исключены из релизного JAR. Исторические документы не заменяют проверки текущей версии. Гарантированный результат поиска в любом сидe и прирост FPS на устройстве пользователя не заявляются.

Исследования: 27 уникальных узел исследований, все 180 слов на меди (1440 вариантов стадий/воска), медные рецепты только по словам кодексов в инвентаре. Создание артефактов требует изучения, находки остаются пригодными к использованию. Великие формулы закрыты до изучения, кроме админского вызова; обычный способ их изучения ещё не добавлен.
