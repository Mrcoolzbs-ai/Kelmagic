# KelMagic 1.7.0 — передача проекта

Платформа: Minecraft 1.21.1 / NeoForge 21.1.256 / Java 21, kelmagic/dev.kelmagic.
Прочитать START_HERE.md, CATALOG-1.7.0.md и VERIFICATION-1.7.0.md.

Текущая задача: уникальные эффекты слов и мира, комбинации, нейтральная подсказка, сильное притяжение, самоповреждение mina, смерти скриптера, контактное магическое горение, кассеты/дека/плеер. Все десять пунктов реализованы. Восьми специальным словам сохранены их роли, а 172 профиля различаются операцией/материалом/формой/свойствами, не только числовыми значениями. 16 специальных сочетаний и прежнее mina liv pir.

Новый код: MagicAudio; audio/* (предметы, блок/BlockEntity, меню); client/AudioScreens; network/TapeSelect; server/EntitySpells и WorldSpells; core/SpellSynergies; server/Playback (контекст смерти). Изменения: SpellParser/ExpandedSpellEffects, MagicDamage, ScripterItem, ArcaneFire, CodexScreen, MagicComponents.

Данные: words/effects/synergies.json. Генераторы: tools/generate_effects_1_7.py и generate_audio_1_7.py. Аудит: verify_revision_1_7.py. Генераторы исторических версий не запускать поверх актуальных ресурсов: они могут вернуть прежние повторяющиеся эффекты.

Кассеты используют существующий recorded_spell, плеер — vanilla CONTAINER и active_tape (0..7). Только записанные допустимые кассеты разрешены. Сохранение меню происходит при каждой правке. Удерживаемый плеер заблокирован; в анонимном Slot использовать захваченный inventoryIndex, а не унаследованное Slot.index: оно становится номером меню и приводит к разблокировке держателя.

Дека: два входа/один выход, 100 тиков за слово, скриптер не расходуется. При смене входа/занятом выходе прогресс отменяется; выгрузка/перезапуск сохраняют время и запись. Входы и выход выпадают при разрушении. Не добавлены hopper capabilities.

Цена плеера max(1,ceil(0.3*сумма букв)), cooldown и durability отсутствуют. Прямое самоповреждение использует источник без attacker, иначе vanilla self-PvP откажет. Контактное горение — LivingDamageEvent.Post только для принятого боевого урона; не для фона/arcane ticks. no неизвестного обратного действия не должен запускать прямой эффект.

Мир: ограниченные размеры, проверки прав/загруженности, защитные события размещения и ломания. Не трогать BlockEntity/бедрок; не замещать твёрдые блоки при создании и не замуровывать существ. lom использует CommonHooks.fireBlockBreak и destroyBlock без лута, проверяя hardness >=0. garden содержит воду в центре. Lightning использует штатную GameRule логику огня, не нужно полностью запрещать молнию при doFireTick=false.

Первые шесть индексов заметок, канонические глифы/шрифт, модели брони и существующие текстуры сохранены. sin — выход; nis вместо zin согласован пользователем. Не добавлять z/w без согласования.

Финальные проверки: 1641 core, 91 серверный GameTest, 1104 asset checks, 376 word/6 artifact layout checks, BUILD SUCCESSFUL. Нативный клиент, два реальных клиента и шейдеры не проверены. Структуры/естественная добыча рукописей пока не добавлены.
