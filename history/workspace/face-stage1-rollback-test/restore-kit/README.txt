Откат статического лица, этап 1

Полное исходное состояние сохранено в оригинальном KelMagic-1.23.0-Source.zip.
Этот компактный комплект содержит все исходные изменённые файлы и оригинальный JAR.

Распакуйте комплект в отдельную папку, НЕ поверх проекта.
Проверка: python RESTORE.py --project /path/to/KelMagic
Применение: python RESTORE.py --project /path/to/KelMagic --apply

Скрипт восстанавливает 5 исходных файлов и удаляет добавленные файлы этапа 1.
При дальнейших пользовательских изменениях он остановится, ничего не перезаписав.
Для установленной игры удалите face-stage1 JAR и поставьте kelmagic-1.23.0-original.jar.
Не держите оба JAR одновременно. GeckoLib не менять.
Генерируемые build/run и миры скрипт не трогает. После отката исходников пересоберите проект.
