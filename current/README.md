## Зависимости и сборка

Java 21, Minecraft 1.21.1, NeoForge 21.1.256, GeckoLib 4.9.3; Curios NeoForge 9.5.1 для носимых аксессуаров. Сторонние JAR не хранятся в Git: поместите официальные библиотеки в `KelMagic/libs/`.

```sh
cd current/KelMagic
bash gradlew -I tools/recovery/binary-build.init.gradle build -x eyeStateTest
bash gradlew -PwithCurios=true -I tools/recovery/binary-build.init.gradle -I tools/artifact-r14/gametest.init.gradle runGameTestServer
```

JAR R14 выдан отдельно в чате; эта публикация коммитит исходники и ресурсы, не создаёт GitHub Release и не добавляет бинарные зависимости. SHA-256 выданного JAR: `07b2f6de53fe01adcc926905bf8c9fb5e7eb7b9bb1af22484377dc845ef20cf1`.

## Проверки

23/23 новых GameTest с Curios и 23/23 без него; 9 435 новых проверок логики; 68 143 прежних проверки ядра. Прежний GameTest: 196/201, те же пять известных сбоев. `eyeStateTest` исключён из-за прежнего `continuous pulse`. Статическая проверка: 579 проверок; рецепты не менялись. Один прежний тест снаряда адаптирован к реальному времени полёта с сохранением проверки урона и отсутствия дебаффов.

Нативный клиент не запускался: технические UV-рендеры не являются игровыми скриншотами. Посадку/анимацию брони, звук, редстоун и сетевую совместимость нужно проверить вручную. Подробный чек-лист — в QA-R14.md.

Логи, миры, кеши, сборочные пакеты и токены исключены из Git. В архиве исходников из чата остаются журналы проверок.
