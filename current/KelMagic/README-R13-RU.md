# KelMagic 1.34.0 R13 — Роща и одобренный контент

Тестовая сборка для Minecraft Java 1.21.1 / NeoForge 21.1.256. Требуется GeckoLib 4.9.3; Curios 9.5.1 необязателен.

## Главное в R13
- Исправлено пробуждение рощи: удаляются стволы, листва и корни, пересекающие границу рощи; после очистки гарантированно подбираются пригодные места для сумеречных деревьев.
- Магическая трава больше не использует block entity на каждом блоке и не строит пространственный градиент. Видимая поверхность рисуется одним пакетным клиентским проходом, весь покров синхронно переливается; волны от блоков маны сохранены. Крайний фиолетовый оттенок затемнён.
- Добавлены одобренные инструменты: плавящая кирка, жильная кирка, мотыга 9×9, землемерная лопата, садовый серп.
- Добавлены камень возврата и фонарь искателя.
- Добавлены сапоги садовника, перчатки строителя, кольцо собирателя, кулон последнего вздоха, плащ угасающего жара и брошь хранителя.
- Добавлен отдельный комплект архивариуса; каждая часть даёт +2 маны и имеет собственный голубой облик.
- Добавлены приёмник эха, изолятор эха и музыкальный резонатор; кассетная система сохранена.
- Удалена отдельная вкладка/гипотеза медных письмен. Существующие блоки оставлены для совместимости старых миров.
- Творческий кодекс открывает просмотр всех гипотез без выдачи исследовательского прогресса выживанию.

## Уже включённые основы
Подставка образцов, соединяемые шкафы архивариуса и рукописей, полная сумеречная древесина, живое волокно, резонансное стекло и чернила архивариуса сохранены и связаны с существующей системой исследований.

## Установка
1. Установить NeoForge 21.1.256 для Minecraft 1.21.1.
2. Поместить GeckoLib 4.9.3 и JAR KelMagic в `mods`.
3. Curios 9.5.1 можно установить дополнительно для аксессуарных слотов.
4. Сделать резервную копию мира перед обновлением тестовой сборки.

Полные результаты проверок находятся в `QA-R13.md`, покрытие требований — в `APPROVED-COVERAGE-R13.md`.
