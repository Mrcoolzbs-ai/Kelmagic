# KelMagic 1.35.0 — R14 Artifacts TEST

**Экспериментальная сборка, не стабильный релиз. Сначала сделайте копию мира.**

Основа: `current/KelMagic` из Kelmagic, версия 1.34.1 R13.1 TEST. Это полный обновлённый KelMagic, **не отдельный аддон**: замените прежний KelMagic JAR, не устанавливайте два одновременно.

## Установка

- Minecraft Java **1.21.1**, **Java 21**.
- NeoForge **21.1.256** — версия, на которой выполнены проверки.
- GeckoLib NeoForge **4.9.3** (нужен исходному моду).
- Curios NeoForge **9.5.1 для 1.21.1** — для новых носимых аксессуаров. Использован API приложенного JAR. Без Curios мод загружается, но аксессуары не дают пассивных эффектов из обычного инвентаря.
- JAR KelMagic R14 в `mods` и на клиенте, и на сервере. Сторонние зависимости в него не встроены.

**Рецептов R14 не добавлено.** Новые предметы доступны в творческой вкладке KelMagic и через `/give kelmagic:<id>`. Новых исследований, способов получения в выживании и страниц кодекса для R14 нет: управление описано в подсказках и этом документе.

## Управление

Клавиши переназначаются в категории «Артефакты KelMagic».

| Клавиша | Действие |
|---|---|
| G | Взять 1 ману из надетого медальона запасного сердца |
| Shift + G | Вложить 1 ману в медальон (отдельная ёмкость 10) |
| H | Потратить полный заряд сумеречной росы, снять все вредные статусы, огонь и опутывание |
| Y | Поднять/отпустить один выброшенный предмет перчатками |
| B | В полном комплекте неподвижной опоры включить/выключить стойку, находясь на земле |
| ПКМ | Активное действие оружия, инструмента или устройства |

Новые аксессуары работают **только надетыми в активные Curios-слоты**. Созданы отдельные `kelmagic_*` слоты: два кольца и по одному слоту для амулета, браслета, серьги, перчаток, оберега, пояса, плаща. Нельзя надеть дубликат одного нового аксессуара. Косметические/выключенные слоты не дают эффекта. Браслет обратного эха — используемый предмет с перезарядкой, не пассивный Curios.

## Чаша → кристалл → молоточек

1. Поставьте чашу, **на неё** кристалл задержанного слова, **на него** молоточек. Предмет блока в руке позволяет ставить эту колонну, не активируя чашу вместо установки.
2. ПКМ по чаше без предмета блока в руке вносит до 5 личной маны с потерей 5%; Shift+ПКМ забирает до 5 в пределах максимума игрока. Вместимости: **32 / 128 / 512**.
3. ПКМ по кристаллу включает запись на 20 секунд и очищает прошлую формулу. Произнесите **1–3 слова Кэл**: одной фразой или последовательно. Запись не списывает личную ману.
4. ПКМ по молоточку или **передний фронт** редстоун-сигнала исполняет записанную формулу. Минимальный интервал 1 секунда; удерживаемый сигнал сам по себе не повторяет заклинание.
5. Цена — сумма длин слов, только из нижней чаши. Недостаток маны не оплачивается здоровьем владельца. Формула сохраняется в блоке после перезапуска; незаконченная сессия записи не сохраняется.
6. Область центрируется на кристалле; направленная магия выбирает случайный видимый твёрдый блок в пределах 24 блоков (или меньшей настроенной дальности). При отсутствии подходящей цели нет списания. Случайные выборки не равновероятны по всем блокам мира.

Великие обряды, неопределённые формулы и чистый выбор без действия не исполняются. Формула, требующая живого адресата, не получает его автоматически из блока: она может не дать эффекта; это не универсальная автоматизация всех заклинаний. Принятая попытка с подходящей целью оплачивается до исполнения, даже если само действие оказалось неприменимо. Обелиски допуска и немого неба учитываются. Действия идут от владельца через серверного исполнителя, без копирования его инвентаря/исследований.

## Уточнения механик

- **Немая застёжка:** запрещает весь обычный чат и стандартные команды общения, магическую речь, звуки сущности, звуки её ближайших действий и игровые вибрации. Невербальные предметы разрешены. Произвольные команды/каналы сторонних модов и звуки без связи с игроком не имеют гарантии совместимости.
- **Сумеречная роса:** снимает все, а не один вредный статус; полезные остаются. Ночью на магической траве постепенно набирает заряд.
- **Основание запретного шага:** заменяет блок непосредственно под любым концом пары порогов; проверяются источник и назначение, поэтому блокируется вход с обеих сторон.
- **Корневая чаша:** стоя на магической траве, добавляет по 0,1 маны в секунду игрокам в радиусе 5. Несколько чаш не суммируются. Животных не лечит.
- **Щит чужой фразы:** стандартная защита щитом и отдельное парирование магического снаряда спереди в первые 5 тиков поднятия, затем перезарядка 100 тиков. Возврат половины записанной стоимости ограничен личным максимумом. Новые снаряды слов имеют достоверную оплаченную цену; при нескольких снарядах она делится, а не дублируется. Снаряды NPC и сторонние/ванильные магические снаряды без цены могут поглощаться, но не создают ману из выдуманной цены.
- Ради парирования BOLT игрока и мага теперь настоящий летящий снаряд, а не мгновенное попадание. Дальность/поведение старых снарядных заклинаний следует дополнительно оценить в игре.
- **Обелиск допуска:** владелец меняет список доверенных именной биркой с именем находящегося онлайн игрока; не является универсальной системой приватов для чужих модов.
- **Секатор:** сохраняет запрет случайного роста/костной муки для выбранного растения; защита от бесконечного накопления — 128 меток на владельца, 4096 на мир. Сторонний рост с собственным исполнителем может потребовать совместимости.
- Мост исчезает через 10 секунд. Корни защиты исчезают через 3 секунды. Сохранённые временные блоки с истёкшим сроком удаляются после загрузки чанка.

## Сборка исходников

В архиве исходников нет сторонних библиотек, Gradle-кеша, миров, токенов и скомпилированных зависимостей. Поместите в `libs/`:

- `geckolib-neoforge-1.21.1-4.9.3.jar`;
- `curios-neoforge-9.5.1-1.21.1.jar` (приложенный к задаче файл).

Под Java 21, из корня проекта:

```bash
./gradlew -I tools/recovery/binary-build.init.gradle build -x eyeStateTest
./gradlew -PwithCurios=true -I tools/recovery/binary-build.init.gradle -I tools/artifact-r14/gametest.init.gradle runGameTestServer
./gradlew -I tools/recovery/binary-build.init.gradle -I tools/artifact-r14/gametest.init.gradle runGameTestServer
```

Windows: `gradlew.bat` вместо `./gradlew`. Флаг `-PwithCurios=true` добавляет Curios в среду запуска; для компиляции API JAR нужен и без флага. Первая сборка загружает Gradle/NeoForge из интернета.

Генераторы новых ресурсов: `tools/artifact-r14/assets.py`, `armor_atlases.py` (Python/Pillow и FFmpeg). Готовые ресурсы уже включены, запускать генератор для обычной сборки не нужно. `artifactArmorProof` экспортирует реальную запечённую Java-геометрию; `render_proofs.py` рисует технический UV-просмотр, **не снимок клиента Minecraft**. История внесённых интеграций — `integrate.py`; повторно запускать её поверх уже изменённого проекта нельзя.

Результаты и ограничения проверки — `QA-R14.md`. Полный список номеров/ID/подсказок — `ARTIFACT-CATALOG-R14.md`.
