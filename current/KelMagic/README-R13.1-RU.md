# KelMagic 1.34.1 R13.1 — исправление кодекса и визуального стиля

**НЕСТАБИЛЬНАЯ ВЕРСИЯ / PRE-RELEASE.** Не предназначена для использования без резервной копии мира.

Тестовая сборка для Minecraft Java 1.21.1 / NeoForge 21.1.256. Требуется GeckoLib 4.9.3; Curios 9.5.1 необязателен.

## Исправлено
- Устранён вылет при сохранении творческого кодекса на разделе «Наполнение»: компонент `codex_section` теперь корректно сохраняет раздел 8.
- Для пяти инструментов, шести аксессуаров, камня возврата, фонаря искателя, одеяний архивариуса и трёх звуковых блоков добавлены 17 справочных записей в существующий кодекс. Каждая объясняет назначение, точное управление, ограничения и способ создания; рецепты показаны на соседних страницах.
- Новые предметы перерисованы в стиле KelMagic: 32×32, тёмные контуры, ступенчатая светотень, золото, бирюзовая магия и самостоятельные силуэты.
- Приёмник эха, изолятор эха и музыкальный резонатор получили собственные текстуры вместо временных ванильных материалов.
- Кулон последнего вздоха теперь лишь продлевает запас воздуха, а не даёт фактически бесконечное дыхание.

## Сохранено из R13
Исправления рощи, пакетный рендер магической травы, весь одобренный набор предметов, творческий просмотр гипотез и совместимость старых медных world ID сохранены. Система исследований и «Слова Кэл» не переделывались.

## Установка
1. Установить NeoForge 21.1.256 для Minecraft 1.21.1.
2. Поместить GeckoLib 4.9.3 и JAR KelMagic в `mods`.
3. Curios 9.5.1 можно установить дополнительно для аксессуарных слотов.
4. Сделать резервную копию мира перед обновлением тестовой сборки.

Подробности проверки — `QA-R13.1.md`. Полное покрытие исходного объёма R13 — `APPROVED-COVERAGE-R13.md`.
